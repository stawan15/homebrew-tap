# stawan15/homebrew-tap

Homebrew tap for installing **kamal-tui**.

## Install

```bash
brew tap stawan15/tap
brew install kamal-tui
```

## Upgrade

```bash
brew update
brew upgrade kamal-tui
```

## Uninstall

```bash
brew uninstall kamal-tui
```

## Formula

- `Formula/kamal-tui.rb`
